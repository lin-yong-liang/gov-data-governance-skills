# 政务数据质量六性与评分说明

依据 GB/T 36344-2018《信息技术 数据质量评价指标》，结合政务数据治理实践整理。

## 1. 完整性（权重 25%）

**定义：** 应存在的数据是否完整存在，必填字段是否缺失。

| 检查点 | 说明 |
|---|---|
| 字段空值率 | 必填字段的 NULL / 空字符串比例 |
| 数据项缺项 | 目录声明的数据项在实际数据中缺失 |
| 关联记录缺失 | 办件、证照等记录找不到对应主体 |
| 记录完整性 | 应报未报、应汇未汇 |

严重级别：主键/关联键缺失 → 高；一般字段缺失 → 中；展示字段 → 低。

## 2. 准确性（权重 25%）

**定义：** 数据是否真实、正确反映客观对象。

| 检查点 | 说明 |
|---|---|
| 权威源比对 | 本数据与权威源不一致的数量 |
| 业务逻辑校验 | 金额≥0、办结时间≥受理时间、年龄合理范围 |
| 数值合理性 | 统计值异常跳变、离群值 |
| 状态有效性 | 死亡人员仍有办件、注销法人仍有业务 |

严重级别：影响业务办理或对外发布 → 高；影响分析 → 中；个案 → 低。

## 3. 一致性（权重 20%）

**定义：** 跨表、跨系统、跨来源的数据是否相互匹配。

| 检查点 | 说明 |
|---|---|
| 汇总与明细 | 总数应等于分项之和（允许既定舍入差） |
| 跨系统一致 | 人口库与民政、人社、卫健数据比对 |
| 状态一致 | 同一主体在不同系统的状态是否冲突 |
| 编码一致 | 同一概念使用相同代码集 |

严重级别：基础库主体状态冲突 → 高；编码不统一 → 中；历史遗留 → 低。

## 4. 规范性（权重 15%）

**定义：** 数据是否符合标准、格式和值域要求。

| 检查点 | 说明 |
|---|---|
| 主体标识 | 身份证号 18 位、统一社会信用代码 18 位 |
| 行政区划 | 6 位行政区划代码有效性 |
| 日期时间 | 格式统一、无非法日期 |
| 枚举值 | 性别、证件类型、办件状态在值域内 |
| 命名与代码 | 符合数据元标准 |

严重级别：主体标识错误 → 高；枚举越界 → 中；格式不统一 → 低。

## 5. 时效性（权重 10%）

**定义：** 数据是否在约定时间内更新并可获取。

| 检查点 | 说明 |
|---|---|
| 更新周期 | 实际更新间隔与目录声明一致 |
| 数据就绪 | T+1 数据在约定时间前可用 |
| 接口延迟 | 共享接口响应时间与延迟 |
| 状态更新 | 死亡、注销、迁出等变更及时同步 |

严重级别：超过 2 倍约定周期 → 高；1.5–2 倍 → 中；轻微 → 低。

## 6. 可访问性（权重 5%）

**定义：** 数据能否被授权方获取、理解和使用。

| 检查点 | 说明 |
|---|---|
| 元数据完备 | 目录条目、数据项说明完整 |
| 接口可用 | 共享接口可用率、鉴权成功率 |
| 权限可用 | 授权方按流程可获得数据 |
| 文档可用 | 数据字典、使用说明齐全 |

严重级别：接口不可用影响共享 → 高；元数据缺失 → 中；文档不全 → 低。

## 评分规则

- 维度得分 = 100 ×（1 − 违规率）
- 违规率 = 违规记录数 / 检查记录数
- 总分 = Σ（权重 × 维度得分）
- 未执行检查项标 SKIP，该维度记"未评估"，不得默认 100 分
- 评级：≥95 优；85–95 良；70–85 中；<70 差

## 严重级别与整改时限

| 级别 | 判定 | 时限 |
|---|---|---|
| 高 | 核心字段错误、影响共享/办件/对外发布 | 24 小时 |
| 中 | 非核心字段、影响分析不影响办理 | 5 个工作日 |
| 低 | 展示性、格式性、个案 | 30 天 |
