# 指标差异根因分类与诊断指南

本文件补充 SKILL.md 中引用的根因分类，供对账时逐项排除。

## 一、定义漂移

**表现：**

- 两个来源对同一指标名称的理解不同
- 指标口径变更后，一方已更新、一方未更新
- 机构改革、事项合并导致统计对象变化

**诊断步骤：**

1. 找到两边指标字典/需求文档
2. 对比业务定义、分子分母、统计对象
3. 查看最近一次口径变更时间
4. 确认变更是否通知到所有下游

**修复：** 由数据 Owner 裁定唯一口径，更新指标字典，保留变更记录。

## 二、过滤条件差异

**表现：**

- 一边包含作废、测试、撤销数据
- 地区、事项类型、业务状态范围不同
- 一边有额外排除条件（如"不含重复办件"）

**诊断步骤：**

1. 并排列出两边 WHERE 条件
2. 逐条标注"有/无/不同"
3. 分别去掉可疑条件跑数，观察差异变化
4. 量化每个条件影响的行数

**修复：** 统一过滤条件；若业务确实需要不同范围，拆成两个指标。

## 三、关联方式差异

**表现：**

- INNER JOIN 导致主体缺失的记录被丢弃
- 关联键不同（身份证号 vs 办件编号）
- 多对多关联导致行数放大

**诊断步骤：**

1. 对比 JOIN 类型（INNER / LEFT / FULL）
2. 对比关联键及清洗规则（去空格、大小写、补零）
3. 统计关联前后行数
4. 检查一对多、多对多关系

**修复：** 统一关联逻辑；缺失主体单独统计，不能静默丢弃。

## 四、统计粒度差异

**表现：**

- 按办件 vs 按事项 vs 按材料
- 按申请人 vs 按自然人 vs 按法人
- 明细汇总后再汇总导致重复计数

**诊断步骤：**

1. 明确"一行代表什么"
2. 检查 GROUP BY 字段
3. 检查是否在同一层级汇总
4. 用最小样本手工验算

**修复：** 统一粒度；跨粒度指标需明确换算规则。

## 五、去重逻辑差异

**表现：**

- DISTINCT 字段组合不同
- 一边按调用次数，一边按调用方去重
- 历史版本未去重，同一主体多条记录

**诊断步骤：**

1. 对比 DISTINCT / ROW_NUMBER / GROUP BY 逻辑
2. 确认去重键
3. 确认取最新版本的规则（时间、版本号）
4. 统计去重前后数量

**修复：** 明确去重键与版本规则，写入指标字典。

## 六、时间截断与时区差异

**表现：**

- 受理时间 vs 办结时间 vs 入库时间
- 自然日 vs 工作日
- 数据截止时间不同（0 点快照 vs 8 点快照）
- 时间字段格式混用

**诊断步骤：**

1. 对齐时间字段名称与含义
2. 确认统计期间边界（含头含尾）
3. 确认时区与格式
4. 确认双方数据截止时间

**修复：** 指标字典明确时间口径；报表显著位置标注数据截止时间。

## 七、刷新延迟

**表现：**

- 一边实时、一边 T+1
- 批量任务未完成、分区缺失
- 上游补数后下游未重跑

**诊断步骤：**

1. 记录双方取数时间
2. 检查调度任务状态与最近成功时间
3. 检查分区是否完整
4. 用同一时点快照重新取数

**修复：** 对账前确认数据就绪；补数后触发下游重算。

## 八、加工缺陷

**表现：**

- 重复跑批导致数据翻倍（幂等性缺失）
- 新增地区/事项未纳入加工范围
- 类型转换丢精度
- NULL 被当作 0 或直接排除

**诊断步骤：**

1. 检查任务日志与重跑记录
2. 检查分区与过滤白名单
3. 对比明细与汇总
4. 用边界样本验证 NULL、0、负数处理

**修复：** 修复加工逻辑，补质量监控规则，增加幂等校验。

## 快速判定表

| 现象 | 优先怀疑 |
|---|---|
| 差异固定为某个比例 | 过滤条件、粒度 |
| 差异集中在某地区/部门 | 数据未同步、加工范围遗漏 |
| 差异随日期扩大 | 刷新延迟、重复跑批 |
| 差异为整数倍 | 多对多关联、重复计数 |
| 差异只在月末出现 | 时间截断、跨期归属 |
| 差异时有时无 | 任务调度、补数未重跑 |
| 小样本对得上、全量对不上 | 去重、分页、并行写入 |
