# 标注质量评估指南

## 一、标注规范检查清单

在评估标签质量前，先确认标注规范是否具备：

- [ ] 标签体系定义（每个标签的含义、边界）
- [ ] 正例/负例/难例示例
- [ ] 多标签场景的互斥/共存规则
- [ ] 标注粒度（词/句/段/文档/记录）
- [ ] 不确定情况的处理方式（弃标/待定/多数票）
- [ ] 标注工具与导出格式
- [ ] 标注人员培训与考核
- [ ] 质检流程与抽检比例
- [ ] 版本管理与变更记录

规范缺失时，先修规范，再谈标签质量。

## 二、标签准确率

### 抽样

- 每个标签类别至少 100 条；稀有类别全量
- 总样本不少于 384（95% 置信度、±5% 误差）
- 分层：按类别、来源、时间、标注员

### 计算

```
标签准确率 = 复核正确的样本数 / 复核样本总数
```

同时报告：

- 各标签的精确率、召回率（如可判定）
- 混淆矩阵
- 错误类型分布（定义不清、边界模糊、标注员疏忽、工具问题）

### 判定参考

| 准确率 | 结论 |
|---|---|
| ≥95% | 合格 |
| 90–95% | 有条件合格，需针对错误类型整改 |
| <90% | 不合格，需重新标注或修订规范 |

## 三、标注一致性（Cohen's κ）

### 适用

两名标注员对同一批样本独立标注，标签为类别型。

### 计算

```
Po = 一致样本数 / 总样本数
Pe = Σ(标注员A各类别比例 × 标注员B各类别比例)
κ  = (Po − Pe) / (1 − Pe)
```

### 解释（Landis & Koch）

| κ | 一致性程度 |
|---|---|
| <0 | 差于随机 |
| 0–0.20 | 轻微 |
| 0.21–0.40 | 一般 |
| 0.41–0.60 | 中等 |
| 0.61–0.80 | 较强 |
| 0.81–1.00 | 几乎完全一致 |

高质量数据集建议 κ≥0.8；0.6–0.8 需分析分歧原因；<0.6 需修订规范并重新培训。

### 使用脚本

```bash
python scripts/cohen_kappa.py --input labels.csv --col-a annotator_a --col-b annotator_b --threshold 0.8
```

输入 CSV 至少包含两列标注结果，行一一对应；空值行会被跳过。

## 四、多标注员场景

- 三人以上：用 Fleiss' κ 或 Krippendorff's α
- 有连续值/多标签：用 ICC、Krippendorff's α
- 有金标准：直接算准确率、召回率
- 本 skill 脚本只覆盖两人 Cohen's κ；其他指标建议用统计工具计算后填入报告

## 五、常见标注质量问题

| 问题 | 表现 | 处理 |
|---|---|---|
| 定义模糊 | 同一案例不同标注员判断不同 | 补边界案例，修订规范 |
| 类别不平衡 | 稀有类被忽略或过度标注 | 分层抽样、过采样、专门培训 |
| 标注员漂移 | 前期和后期的标准不一致 | 定期校准、盲标复核 |
| 复制粘贴 | 连续样本标签完全相同 | 检查重复率、时间戳 |
| 机器预标污染 | 预标注错误被原样接受 | 人工复核预标结果，记录修改率 |
| 测试集泄漏 | 训练集与评测集重复 | 去重、n-gram 重叠检测 |
| 标注粒度不一致 | 有的标整句、有的标词 | 明确粒度并重新标注 |

## 六、标签质量报告内容

- 标签体系与规范版本
- 抽样方法与样本量
- 准确率及置信区间
- κ 及解释
- 混淆矩阵与错误类型分布
- 各标注员/各批次表现
- 整改建议与复评计划

## 七、注意事项

- 不要让标注员评估自己标注的样本
- 复核样本要独立随机抽取，不能只抽争议样本
- κ 低不一定是标注员问题，可能是标签定义本身不可判定
- 标签质量评估结果应回写到数据集说明文档
