# 高质量数据集三维度 17 项指标评测细则

> 本文件是 TC609《高质量数据集 质量评测规范》的**落地拆解**，用于内部评测与申报准备。正式评测以全国数标委发布的正式文本为准；若正式文本的指标项、权重或阈值不同，以正式文本优先。

## 评分总则

- 每项指标 0–100 分
- 每个维度满分 100 分，维度得分 = Σ（指标权重 × 指标得分）/ 100
- 三个维度均需 ≥90 分，且无否决项，方可认定为高质量数据集
- 总分仅作展示，不替代维度门槛

## 维度 A：说明文档（5 项）

### A1 数据集基本信息（权重 20%，目标完整率 100%）

**应具备要素：**

- 数据集名称、版本号
- 提供方、数据 Owner、联系方式
- 覆盖范围（地域、对象、业务）
- 时间跨度与数据截止时间
- 更新周期与更新方式
- 数据规模（记录数、字段数、存储大小）
- 用途与适用场景

**评分：** 得分 = 100 × 已具备要素数 / 应具备要素数。
**证据：** 数据卡、说明文档、目录条目。

### A2 字段级数据字典（权重 25%，目标覆盖率 ≥95%）

**应具备要素：**

- 字段中文名、英文名
- 业务定义（无歧义）
- 数据类型、长度、精度
- 是否必填、缺失含义
- 值域/代码集及引用标准
- 示例值（脱敏后）
- 是否敏感、是否个人信息

**评分：** 覆盖率 = 已完整说明字段数 / 总字段数；得分 = min(100, 100 × 覆盖率 / 95%)。

### A3 采集与来源说明（权重 20%，目标完整率 100%）

**应具备要素：**

- 来源系统与权威源
- 采集方式（接口/批量/人工录入）
- 采集频率与时间范围
- 抽样方法（如适用）
- 清洗与预处理规则
- 数据血缘（上游、下游）

**评分：** 得分 = 100 × 已具备要素数 / 应具备要素数。

### A4 标注说明（权重 20%，目标完整率 100%；无标注场景记 N/A）

**应具备要素：**

- 标注任务定义与标签体系
- 标注规范（含边界案例）
- 标注流程与工具
- 标注人员资质与培训
- 质检方式（双人标注、抽检比例）
- 一致性指标（κ 或一致率）
- 标注版本与变更记录

**评分：** 有标注则按要素完整率；无标注场景记 N/A，并在报告中说明。

### A5 授权与合规声明（权重 15%，目标完整率 100%）

**应具备要素：**

- 数据权属与来源合法性说明
- 使用许可与再分发限制
- 分类分级结果（核心/重要/一般）
- 个人信息与敏感个人信息标识
- 共享/开放属性及依据
- 出境情况说明（如适用）

**评分：** 得分 = 100 × 已具备要素数 / 应具备要素数。任一要素缺失且涉及敏感数据，触发否决项。

## 维度 B：数据质量（8 项）

### B1 完整性（权重 15%，目标 ≥98%）

**计算：**

- 必填字段完整率 = 1 − 必填字段空值数 / 必填字段总记录数
- 记录完整率 = 有效记录数 / 应到记录数

**评分：** 得分 = min(100, 100 × 实际完整率 / 98%)。
**证据：** SQL 空值统计、任务对账、应到未到清单。

### B2 准确性（权重 20%，目标 ≥95%）

**计算：**

- 权威源一致率 = 与权威源一致记录数 / 比对记录数
- 内容正确率 = 抽样正确记录数 / 抽样记录数
- 业务逻辑正确率 = 通过逻辑校验记录数 / 校验记录数

**评分：** 得分 = min(100, 100 × 实际正确率 / 95%)。
**证据：** 权威源比对 SQL、抽样复核表、逻辑校验规则。

### B3 一致性（权重 15%，目标 ≥95%）

**计算：**

- 跨表一致率（汇总=明细、主表=从表）
- 跨系统一致率（与权威源或关联系统）
- 跨字段一致率（如办结时间≥受理时间）

**评分：** 得分 = min(100, 100 × 实际一致率 / 95%)。

### B4 规范性（权重 15%，目标 ≥90%）

**计算：** 格式、值域、编码、命名符合标准的记录占比。
**评分：** 得分 = min(100, 100 × 实际符合率 / 90%)。
**证据：** 正则校验、代码集比对、行政区划代码表。

### B5 唯一性（权重 10%，目标：主键唯一率 100%，全行重复率 ≤1%）

**计算：**

- 主键唯一率 = 唯一主键数 / 总记录数
- 重复率 = 重复记录数 / 总记录数

**评分：**

- 主键唯一率 <100% 时，得分 = 100 × 主键唯一率
- 重复率 >1% 时，得分 = max(0, 100 − 100 × (重复率 − 1%) / 1%)
- 取两者较低分

### B6 时效性（权重 10%，目标 ≥95%）

**计算：**

- 更新及时率 = 按声明周期更新的批次数 / 应更新批次数
- 数据截止时效 = 最新记录时间与约定截止时间的偏差

**评分：** 得分 = min(100, 100 × 及时率 / 95%)。

### B7 可用性（权重 5%，目标 ≥99%）

**计算：**

- 可解析率 = 成功解析记录数 / 总记录数
- 字段可读率 = 有明确业务含义的字段数 / 总字段数
- 缺失值可解释率 = 有缺失说明的字段数 / 存在缺失的字段数

**评分：** 三项加权平均；得分 = min(100, 100 × 实际值 / 99%)。

### B8 安全与隐私（权重 10%，目标：PII 泄露 0，脱敏率 100%，重要数据标识 100%）

**核验：**

- 敏感字段是否全部标识
- 脱敏规则是否覆盖所有对外/测试场景
- PII 扫描是否发现完整证件号、手机号、住址等
- 重要数据是否按要求识别、目录化、备案

**评分：**

- PII 泄露 >0 或未脱敏 → 本项 0 分，并触发否决项
- 否则按脱敏率、标识率加权

## 维度 C：模型应用（4 项；非 AI 数据集可申请豁免）

### C1 任务适配性（权重 25%，目标清单符合率 ≥90%）

**检查：**

- 数据内容与目标任务匹配（字段、标签、粒度）
- 数据规模满足训练/评测最低要求
- 格式可直接被训练框架读取
- 训练/验证/测试划分合理，无泄漏

**评分：** 得分 = 100 × 已满足清单项 / 应满足清单项。

### C2 标签质量（权重 30%，目标：准确率 ≥95%，κ≥0.8）

**计算：**

- 标签准确率：抽样人工复核，正确标签数 / 抽样数
- 标注一致性：Cohen's κ（双人标注）
- 标签覆盖率：有标签记录数 / 应标注记录数

**评分：**

- 准确率得分 = min(100, 100 × 准确率 / 95%)
- κ 得分 = 100 if κ≥0.8；否则 = max(0, 100 × (κ − 0.4) / 0.4)
- 覆盖率得分 = min(100, 100 × 覆盖率 / 95%)
- 加权：准确率 50%、κ 30%、覆盖率 20%

### C3 代表性与偏差（权重 25%，目标：无系统性缺口）

**检查：**

- 类别分布是否覆盖目标场景
- 地区、群体、时间等子群体是否均衡
- 与真实分布是否存在显著偏移
- 是否存在已知偏差或歧视性样本

**评分：** 专家按清单打分（0/25/50/75/100），需附分布对比图和结论。
**注意：** 此项难有统一数值阈值，报告必须写清评估方法和局限。

### C4 下游增益（权重 20%，目标：有统计显著提升）

**检查：**

- 与基线数据集/无该数据集的模型对比
- 指标提升是否统计显著（置信区间、检验）
- 实验是否可复现（代码、随机种子、超参）

**评分：**

- 有显著提升且可复现 → 90–100
- 有提升但未验证显著性 → 60–89
- 无提升或不可复现 → 0–59
- 无法开展实验 → N/A，需说明理由

## 否决项复核

以下任一情况，评测结论直接为"不通过"：

1. 权属/授权/来源违法
2. 未分类分级，重要数据未识别或未备案
3. 敏感个人信息未脱敏或实际泄露
4. 无说明文档/数据卡
5. 内容违法或侵权
6. 系统性造假

## 报告要求

- 每项指标写清：实际值、目标值、得分、证据、责任人
- N/A 项必须说明原因，不能默认满分
- 维度分与总分同时展示，结论以维度门槛为准
- 附抽样方法、SQL/脚本参数、数据截止时间，保证可复现
