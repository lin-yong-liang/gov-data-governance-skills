# 高质量数据集评测抽样指南

## 一、抽样原则

1. **确定性规则全量扫描**：空值、重复、格式、值域、PII、主键唯一性等可自动判定的规则，优先全量跑，不抽样。
2. **人工复核才抽样**：准确性比对、标签质量、文档符合性等需要人判断的项，采用抽样。
3. **分层覆盖**：按地区、部门、事项类型、时间、主体类型分层，避免样本集中在某一类。
4. **随机可复现**：使用固定随机种子，保留抽样框和样本清单。
5. **留痕**：抽样方案、样本量、执行人、复核人、日期全部归档。

## 二、样本量计算

### 简单随机抽样（比例估计）

公式：

```
n0 = Z² × p × (1 − p) / e²
n  = n0 / (1 + (n0 − 1) / N)    # 有限总体校正
```

- Z：置信水平对应的标准正态分位数（95% → 1.96；99% → 2.576）
- p：预期比例，未知时取 0.5（最保守）
- e：允许误差（如 0.05）
- N：总体规模

### 常用参考值

| 置信度 | 误差 | p=0.5 时 n0 | N=1,000 | N=10,000 | N=100,000 |
|---|---:|---:|---:|---:|---:|
| 95% | ±5% | 384 | 278 | 370 | 383 |
| 95% | ±3% | 1,067 | 513 | 964 | 1,056 |
| 99% | ±5% | 664 | 399 | 622 | 662 |
| 99% | ±3% | 1,844 | 649 | 1,560 | 1,826 |

> 表中数字已做有限总体校正，实际以脚本计算为准。

### 使用脚本

```bash
python scripts/sample_size.py --population 120000 --confidence 0.95 --margin 0.05
```

## 三、分层抽样

### 分层维度建议

| 数据集类型 | 分层维度 |
|---|---|
| 人口/法人基础库 | 地区、主体类型、状态（正常/注销/死亡）、数据来源 |
| 办件/政务服务 | 地区、部门、事项类型、办理状态、时间 |
| 信用/监管 | 行业、主体规模、信用等级、时间 |
| AI 训练集 | 类别、子群体、采集来源、时间 |

### 样本分配

- **按比例分配**：每层样本量 = 总样本量 × 该层规模 / 总体规模
- **重点层保底**：小规模但高风险层（如敏感数据、少数民族地区）设置最低样本量（如 30 条）
- **层内随机**：每层内简单随机或系统抽样

## 四、GB/T 2828.1 适用场景

当评测对象是**批量数据集/分批交付**，且需要按接收质量限（AQL）判定批合格时，可按 GB/T 2828.1 计数抽样：

1. 确定批量 N、检验水平（一般检验水平 II）、AQL
2. 查样本量字码和抽样方案
3. 抽取样本，统计不合格品数
4. 按 Ac/Re 判定该批接收或拒收

注意：GB/T 2828.1 是**批质量判定**，不直接给出数据集整体质量得分；两者可配合使用。

## 五、人工复核抽样要点

### 准确性比对

- 与权威源按主体标识关联
- 每个关键字段抽 100–200 条
- 记录不一致类型（缺失、错误、过期、口径不同）
- 不一致率与置信区间一并报告

### 标签质量

- 每个标签类别至少 100 条，稀有类别可全量
- 双人独立标注至少 10% 且不少于 200 条
- 计算 Cohen's κ；κ<0.8 时需分析原因并重新培训/修订规范

### 文档符合性

- 文档类指标可全量核查（清单逐项打勾），无需抽样
- 若文档数量多，按类型分层各抽 3–5 份

## 六、样本记录模板

| 字段 | 说明 |
|---|---|
| 样本编号 | S-0001 |
| 分层 | 地区/类型/时间 |
| 主体标识 | 脱敏后编号 |
| 抽取方式 | 随机/系统/全量 |
| 复核项 | 准确性/标签/文档 |
| 复核结果 | 正确/错误/不适用 |
| 问题类型 | 缺失/错误/过期/口径 |
| 复核人 | 姓名 |
| 复核日期 | YYYY-MM-DD |

## 七、常见错误

1. 只抽"头部"或"干净"数据，样本不随机
2. 样本量不足却给出精确结论
3. 分层后不按规模分配，小层过度代表
4. 抽样框不更新，漏掉新增数据
5. 复核人知道自己抽的是哪批，产生确认偏差
6. 不记录随机种子，无法复现
7. 把全量规则扫描结果当成人工复核结果
