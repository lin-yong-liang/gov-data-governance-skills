# 数据分类分级与合规（政务/公共数据）

## 法规与标准速查

| 文件 | 要点 |
|---|---|
| 《数据安全法》(2021) | 分类分级保护制度、重要数据目录 |
| 《个人信息保护法》(2021) | 告知同意、最小必要、敏感个人信息 |
| 《网络数据安全管理条例》(2025-01-01 施行) | 分类分级、重要数据、个人信息处理细则 |
| GB/T 43697-2024《数据安全技术 数据分类分级规则》 | 核心/重要/一般三级、重要数据识别 |
| 《政务数据共享条例》(2025-08-01 施行) | 共享安全责任、目录与平台管理 |
| GB/T 39477-2020《政务信息共享 数据安全技术要求》 | 共享场景安全要求 |
| 《公共数据资源授权运营实施规范（试行）》(2025) | 授权运营模式与安全要求 |
| 《公共数据资源登记管理暂行办法》 | 公共数据登记管理 |
| GB/T 35273-2020《个人信息安全规范》 | 个人信息处理实践要求 |
| 《保守国家秘密法》 | 涉密数据，不纳入一般分类分级体系 |

> 政务数据政策更新快，正式交付前核对最新有效版本与本级政府实施细则。

## 政务数据分类

### 按数据主体/业务领域

- **自然人数据**：人口、社保、医保、民政、教育、卫健
- **法人数据**：市场主体、税务、信用
- **自然资源与空间地理**：土地、规划、测绘、不动产
- **电子证照**：身份证、营业执照、资格资质证书
- **社会信用**：红黑名单、信用记录
- **宏观经济**：统计、财政、金融运行数据

### 按共享属性

无条件共享 / 有条件共享 / 不予共享（须有法定依据）

### 按开放属性

无条件开放 / 有条件开放 / 不予开放

### 按敏感程度（内部管理口径）

公开 / 内部 / 敏感 / 涉密（涉密按保密法管理，不进入政务数据共享开放体系）

## 分级

### 核心 / 重要 / 一般（GB/T 43697）

- **核心数据**：关系国家安全、国民经济命脉、重要民生、重大公共利益
- **重要数据**：泄露可能危害国家安全、经济运行、社会稳定、公共健康和安全
- **一般数据**：其余数据，可再按企业/政府内控细分

### 政务常见重要数据

- 大规模人口健康、社保、位置数据
- 重要地理测绘、自然资源数据
- 公共安全、应急管理、能源交通运行数据
- 涉及国防动员、民族宗教等敏感领域数据

### 个人信息标识

敏感个人信息：身份证号、生物识别、医疗健康、行踪轨迹、金融账户、不满 14 周岁未成年人信息。个人信息在分类分级清单中必须单独标识。

### 重要数据流程

识别 → 专家评审 → 形成目录 → 按要求备案 → 落实保护 → 定期评估。

## 分级保护措施矩阵

| 措施 | 一般数据 | 重要数据 | 核心数据 |
|---|---|---|---|
| 存储加密 | 敏感字段加密 | 全量加密 | 全量加密+专库专管 |
| 传输加密 | HTTPS/TLS | 专线+加密 | 专网+加密 |
| 访问控制 | 角色权限 | 最小权限+审批 | 双人授权+强审计 |
| 共享 | 审批 | 安全评估+协议 | 原则不共享 |
| 开放 | 脱敏后开放 | 脱敏+安全审核 | 不开放 |
| 审计 | 定期审计 | 全量操作审计 | 实时监控+审计留痕 |
| 销毁 | 按制度 | 审批后销毁 | 专项管理 |

## 共享与开放安全

- **共享**：依据共享属性执行，落实"谁使用谁负责"；接口鉴权、访问日志、最小必要
- **开放**：开放前安全审查与脱敏，禁止开放敏感个人信息和重要数据
- **授权运营**："原始数据不出域、数据可用不可见"；签订协议、安全评估、全程审计、退出机制
- **交换**：加密传输、身份认证，敏感场景可加水印追溯

## 脱敏方案模板

| 字段 | 敏感类型 | 脱敏算法 | 使用场景 |
|---|---|---|---|
| 身份证号 | 敏感个人信息 | 保留前 6 后 4，中间掩码 | 共享/展示 |
| 手机号码 | 个人信息 | 保留前 3 后 4 | 共享/展示 |
| 姓名 | 个人信息 | 保留姓氏，名掩码 | 展示 |
| 住址 | 个人信息 | 精确到区/街道 | 统计分析 |
| 统一社会信用代码 | 法人信息 | 保留前 2 后 4 | 公示/展示 |
| 证照影像 | 敏感个人信息 | 遮盖关键要素 | 共享 |

脱敏原则：静态脱敏用于测试/开放，动态脱敏用于共享查询/展示；同值同映射，保持关联一致性。

## 合规检查清单

- [ ] 政务数据目录完整，分类分级标注覆盖率 100%
- [ ] 共享属性、开放属性逐项认定，不予共享/开放有法定依据
- [ ] 重要数据目录已识别、评审并按要求备案
- [ ] 开放前安全审查与脱敏，敏感个人信息零开放
- [ ] 授权运营有协议、安全评估、审计与退出机制
- [ ] 个人信息处理有合法基础（履行法定职责或取得同意）
- [ ] 网络日志留存不少于 6 个月
- [ ] 等保测评、密码应用合规
- [ ] 政务数据境内存储；确需出境履行安全评估
- [ ] 安全事件应急预案与演练记录
